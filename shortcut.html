카톡·유튜브 열 때 성경암송 먼저 열기

아이폰 단축어 앱에서 아래를 한 번씩 만들어 주세요. 컴퓨터에서는 등록되지 않고, 아이폰에서만 설정됩니다.

https://redwaterdeer.github.io/Scripture-memory/

이 주소를 복사해 두세요.

카카오톡

  1. 단축어 앱을 엽니다.
  2. 아래 자동화를 누릅니다.
  3. 오른쪽 위 + → 개인 자동화 생성
  4. 앱을 누릅니다.
  5. 열릴 때가 선택돼 있는지 확인하고, 앱 선택에서 카카오톡을 고른 뒤 완료.
  6. 다음을 누릅니다.
  7. 동작 추가 → 검색창에 URL 열기
  8. URL에 위 성경암송 주소를 붙여 넣습니다.
  9. 다음 → 실행 전에 묻기를 끄기 → 완료

유튜브

  1. 위와 똑같이 자동화를 하나 더 만듭니다.
  2. 앱만 YouTube로 고릅니다.
  3. 동작은 같은 URL 열기 (성경암송 주소)입니다.
  4. 실행 전에 묻기를 반드시 끕니다.

카톡이나 유튜브를 누르면 잠시 열린 뒤, 성경암송 화면이 앞으로 옵니다. 아이폰이 다른 앱 실행을 가로채는 것은 막혀 있어서, 카톡이 아예 안 열리게 할 수는 없습니다.
